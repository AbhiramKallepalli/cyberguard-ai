# CyberGuard AI

AI-powered home network security monitor 
for IoT devices - built for non-technical 
homeowners.

## Project Status
🔄 In Development - Specification Phase

## What This Project Does
Detects unusual activity on home networks
using an unsupervised anomaly detection 
model, explains findings in plain English, 
and provides an AI assistant to help 
homeowners decide what action to take.

## Tech Stack
- Flask (backend)
- SQLite + SQLAlchemy (database)
- Isolation Forest (anomaly detection)
- SHAP (explainability)
- Ollama + Phi-3 Mini (local LLM)
- Custom CSS + JavaScript (web interface)

## Dataset
NSL-KDD Network Intrusion Detection Dataset
